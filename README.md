# Digital Eye Strain Helper Website

A website for the Digital Eye Strain Helper application with a dark theme optimized for eye comfort.

## Setup and Running Instructions

1. Make sure you have Node.js installed on your system
   - Download from: https://nodejs.org/

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the server:
   ```bash
   npm start
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

The website will be running locally with all features functional:
- Navigation between pages
- Code block copying
- Download links
- Responsive design

## Features
- Dark theme with blue accents for eye comfort
- Responsive design
- Easy navigation
- Installation instructions
- System requirements
- Direct download links
